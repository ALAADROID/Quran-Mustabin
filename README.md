# القرآن المستبين — Al-Qur'an Al-Mustabin 🌙

An interactive Quran study platform that brings together the **Quran, Arabic word meanings, and Tafsir** in one unified interface.

> **القرآن المستبين** is an ongoing open-source project focused on making it easier to explore the meanings of Quranic words and understand the interpretation of each Ayah.

---

## 📖 About

The project is built around a simple idea:

**Read the Ayah → Explore its words → Understand their meanings → Read its Tafsir.**

The Quran is presented as the main focus of the interface, while supporting panels provide additional linguistic and interpretive information.

Users will be able to interact directly with the Quranic text:

* Select a **word** to explore its Arabic meaning and related linguistic information.
* Select an **Ayah** to view its Tafsir.
* Choose between available Tafsir sources.
* Explore the Quran without leaving the main reading interface.
